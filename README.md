## 必须保留的计分边界

**同一完整输入、同一实际查询轨迹，可以按已校准 R30 模型复算；合成总分不能准确换算官方固定 102 例总分。** 目前未取得官方 102 条完整曲线。

原题 PDF 字面使用 R1，研究根据平台探针反馈采用 R30。证据、原文分歧与适用范围见 [`评分审计`](01_docs/scoring_audit/评分标准与换算边界_交接草稿.md)。这不是官方 checker 源码审阅结论。

相同输入、轨迹和硬门槛，逐例转换：`S30 = max(0, S1 - 29*R)`；必须逐例截零后求和，不能对合成总分套比例预测平台成绩。

## 快速运行

依赖 Python 3.10+ 与支持 C++17 的 `g++`；无需额外 Python 库。

```sh
python -m unittest discover -s 02_tools -p "test_*.py"
python 02_tools/simulate.py --source 03_sources/12_online_149485.cpp --cases 04_data/smoke_7.json --out runs/smoke --mode pipe
```

本仓库按资料所有者要求公开，包含历史本地路径与用户提供的成绩证据。公开前进行了高置信度凭据模式扫描，但这不是对所有可能敏感信息的绝对保证。
